# ImgCompress Mac 设计

用户已确认：MyGo + React，独立 macOS 桌面应用，中文，支持深浅色、批量导入、JPG/PNG/WebP 压缩转换、质量和尺寸设置、无损模式、预览、文件夹导出及 Finder 查看。处理完全离线，默认不覆盖文件。AVIF、动画和 SVG 不在首版支持范围。

## 实现约定

- 单窗口，左侧图片队列、右侧设置、底部进度及导出。
- 复用 MIT 授权的 ImgCompress WASM WebP 编码方式；静态 PNG/JPEG/WebP 输入，拒绝动画以避免丢帧。
- WebP 使用 WASM 编码，JPEG/PNG 使用 Canvas。显式格式转换不能静默替换为其他格式。
- 无损指保留解码像素，禁用缩放，输出 WebP；不承诺保存 EXIF、ICC 或其他元数据。
- 压缩自动模式若变大保留原文件；显式格式转换按所选格式输出。
- Go 只提供输出目录选择、受限文件写入和 Finder 打开。仅导出一个 ZIP，包内图片使用输入名及真实 MIME 扩展名；重名生成数字后缀，压缩包独占创建避免覆盖。
- 受控双并发处理以限制峰值内存；WebP 使用独立 Worker 编码，支持终止并恢复未完成任务，失败逐项显示并允许重试。
- 首版交付本机 Apple Silicon 的 .app 和 .dmg，使用临时签名；不使用用户签名证书、不发布远端。

## 验证

TypeScript 检查、前端构建、文件导出 Go 测试、真实图片格式/尺寸/透明度/无损像素测试，最后检查本地打包与窗口启动。未实际验证的内容须在交付说明中明确。
